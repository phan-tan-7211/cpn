**Mức phí dịch vụ:**

a.  Phí dịch vụ kế toán báo cáo thuế tháng : **theo biểu phí dịch vụ** (chưa bao gồm thuế )

b.  Phí dịch vụ kế toán báo cáo tài chính (BCTC): **tháng lương thứ 13** (chưa bao gồm thuế )

c.  Phí hỗ trợ làm báo cáo kế toán nội bộ: **theo thỏa thuận** đồng/tháng (chưa bao gồm thuế )

d.  **Tổng chi phí : (bao gồm (a) + (b) + (c))/đồng/tháng (**chưa bao gồm thuế )
