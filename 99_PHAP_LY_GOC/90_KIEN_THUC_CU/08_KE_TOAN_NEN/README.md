# 08_KE_TOAN_NEN — KIẾN THỨC KẾ TOÁN NỀN

**TRẠNG THÁI:** REFERENCE

Đây là phần có thể giữ để học/ôn nguyên lý, miễn là không nhầm với chế độ kế toán hoặc luật thuế hiện hành.

## NÊN GIỮ

- nguyên lý tài sản, nợ phải trả, vốn chủ sở hữu;
- khái niệm chi tiêu/chi phí, giá thành;
- phương pháp quản lý/tính giá xuất kho ở góc độ kiến thức;
- bộ chứng từ và logic đối chiếu;
- cẩm nang kế toán tổng hợp cũ để khai thác ý;
- quy trình kế toán chung không gắn deadline pháp luật cụ thể.

## CẢNH BÁO

Nếu một file nền bắt đầu nêu số tài khoản, mẫu BCTC, thuế suất, deadline hoặc nghĩa vụ pháp lý thì phần đó phải kiểm tra lại theo chế độ/văn bản hiện hành. Không coi toàn bộ file là đúng chỉ vì phần nguyên lý cơ bản đúng.
