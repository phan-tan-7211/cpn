# Kiểm tra file XML hóa đơn điện tử - Ngày lập, ngày ký, ngày cấp mã

> Nguồn: Video TRANSCRIPT (Centa Kế toán)

---

## 1. Cài đặt phần mềm

- **Cài đặt 1 trong 2 phần mềm**: EasyInvoice hoặc VNPT Invoice
- Link download: Google "EasyInvoice" hoặc "VNPT Invoice"

---

## 2. Cách kiểm tra

### Bước 1: Mở phần mềm EasyInvoice
- Nhập thông tin đăng nhập (đã được cung cấp từ Centa Kế toán)

### Bước 2: Nhập file XML cần kiểm tra
- Kéo thả file XML vào phần mềm
- Nhấn "Kiểm tra"

### Bước 3: Xem kết quả
- **Ngày lập hóa đơn**: Xem trong file XML
- **Ngày ký**: Xem trong file XML
- **Ngày cấp mã**: Xem trong file XML

---
